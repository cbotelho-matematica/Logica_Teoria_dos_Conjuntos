# Apresentação

Em maio de 2026, após concluir o período de estudos na graduação em Matemática, resolvi investir um tempo no estudo de demonstrações Matemáticas. O objetivo é compreender as construções lógicas necessárias para as demonstrações e estudar não só o raciocínio lógico envolvido, mas a forma de escrita de um texto matemático claro, conciso e com uma dose de estilo literário.

Como objeto de aplicação dessas técnicas, elegi o tema de Teoria dos Conjuntos para tratar mais especificamente. Logo, não deixará de ser uma boa oportunidade de estudo, revisão e profundamento de temas relacionados a este belo campo da Matemática.

Certamente, por questões comodidade e facilidade, aparecerão teoremas relacionados a outros tópicos matemáticos sendo provados para estudo das técnicas. Tomemos isso como um brinde, uma ampliação do nosso escopo com algumas belas amostras grátis.

Vamos à viagem.
